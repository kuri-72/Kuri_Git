## 第一部分：Python 惯用法（最吓人的那批）

这些不是"领域词"，是 Python 的写法。**它们不承载业务信息，只是语法糖。**

| 写法 | 中文 | 它到底在干什么 | 你可以暂时怎么理解 |
|---|---|---|---|
| `self` | 自己 | 表示"这个对象自己" | 一个必须写的占位词，当成"我" |
| `__init__` | 初始化 | 对象创建时自动跑的函数 | 相当于"出厂设置" |
| `__enter__` / `__exit__` | 进入/离开 | 配合 `with` 用，自动开关资源 | `with` 结束时自动关串口/文件 |
| `@dataclass` | 数据类 | 自动生成初始化代码的装饰器 | 只用来"装几个字段"，没有逻辑 |
| `@property` | 属性 | 把函数伪装成变量用 | `obj.ready` 其实是调函数 |
| `def f(x: int) -> str` | 类型标注 | `: int` 和 `-> str` **不强制**，只是提示 | 忽略也不影响运行 |
| `str \| None` | 可以是空 | 这个参数可以传 `None`（空） | "有值或没有" |
| `list[dict]` | 类型说明 | 一个列表，里面装字典 | 不用管，Python 不检查 |
| `**kwargs` | 收集参数 | 把所有没匹配的关键字参数打包成字典 | "剩下的都给我" |
| `ABC` / `@abstractmethod` | 抽象基类 | 规定"子类必须实现这个方法" | 接口约定，防止写漏 |
| `f"{a:.2f}"` | 格式化 | 把数字按 2 位小数塞进字符串 | 打印用 |
| `x += 1` | 累加 | 等于 `x = x + 1` | — |
| `if __name__ == "__main__"` | 程序入口 | 直接运行这个文件时才执行 | "如果是我自己跑" |

> **关键认知**：这些词占了你"看不懂"的 **一半以上**，但它们**不含业务逻辑**。
> 把上表背下来，代码立刻瘦一圈。

## 第二部分：音频层（voice/audio/）

| 英文 | 中文 | 在做什么 | 在哪 |
|---|---|---|---|
| `sample` | 采样点 | 一个音量数值（-32768~32767） | 全局 |
| `samplerate` / `sr` | 采样率 | 每秒采多少个点（16000） | recorder.py |
| `channel` | 声道 | 单声道=1，立体声=2 | recorder.py |
| `frame` | 帧 | 一小块音频（512 个采样点 = 32ms） | vad.py |
| `blocksize` | 块大小 | 一次从声卡读多少点 | recorder.py |
| `rms` | 均方根 | 一段音频的平均音量 | recorder.py |
| `dBFS` | 分贝满刻度 | 音量的对数表示，0 最大，-96 约等于静音 | 全局 |
| `gain` | 增益 | 把音量整体放大 | recorder.py |
| `normalize` | 归一化 | 把音量拉到目标值 | recorder.py |
| `resample` | 重采样 | 16000 ← 48000 的转换 | recorder.py |
| `trim_head` | 掐头 | 丢掉录音开头那段空白 | devices.py |
| `pre_roll` | 预录 | 开口前先缓存的一段（防丢首字） | vad.py |
| `VAD` | 语音活动检测 | 判断"有没有人说话" | vad.py |
| `threshold` | 阈值 | 超过多少就算人声（0.5） | vad.py |
| `silence` | 静音 | 判定"说完了"用的静音时长 | vad.py |
| `utterance` | 一句 | 从开口到说完的一整段 | recorder.py |
| `flush` | 冲刷 | 流结束了，把没结束的那句强制吐出来 | vad.py |
| `device` | 设备 | 麦克风/扬声器 | devices.py |
| `hostapi` | 宿主接口 | Windows 的 MME/DirectSound/WASAPI | devices.py |

## 第三部分：识别层（voice/asr/）

| 英文 | 中文 | 在做什么 |
|---|---|---|
| `ASR` | 语音识别 | 音频 → 文字 |
| `transcribe` | 转写 | 核心动作，就是把音频变文字 |
| `provider` | 提供者 | 一种"可替换的实现"，比如 Whisper 或别的 |
| `model_size` | 模型大小 | tiny/base/small/medium/large-v3 |
| `compute_type` | 计算精度 | int8（省）/ float16（快） |
| `beam_size` | 束宽 | 搜索宽度，越大越准越慢（5） |
| `initial_prompt` | 提示词 | 告诉模型"大概是这些词" |
| `vad_filter` | VAD 过滤 | 先滤掉静音再识别，防幻觉 |
| `segment` | 片段 | 识别结果按时间切成的段落 |
| `language_probability` | 语言置信度 | 判断是中文的把握程度 |
| `realtime_factor` | 实时率 | 音频时长 ÷ 处理耗时，>1 就是比实时快 |
| `hallucination` | 幻觉 | 音频里没人说话时，模型"编"出一段话 |

## 一个练习建议（配合这份表）

挑一个文件，比如 `voice/audio/recorder.py`，做三件事：

1. **把不认识的词圈出来**，用这份表查
2. **标出每个函数"吃进去什么、吐出来什么"**（不用看懂里面）
3. **画出这个文件在数据流里的位置**（它是"听"这一层）

**做完你会发现：能读懂的代码从 30% 变成 80%。**

剩下 20% 是算法细节（比如 VAD 的神经网络），那部分**你不需要懂**，就像你不需要懂 STM32 库函数里怎么操作寄存器。
