# 小72 使用说明

> 说话（打字）控制这盏灯。不需要懂代码。

---

## 一、第一次用

### 1. 插好 USB 转串口

板子 → CH340 模块 → 电脑 USB。**记得 TX/RX 交叉、GND 共地。**

确认驱动正常：设备管理器里能看到 `USB-SERIAL CH340 (COM8)`。
COM 号可能不是 8，无所谓，程序会自动找。

### 2. 填 API key（只做一次）

打开：

```
C:\Users\ROG\Documents\deepseek-harness\default-workspace\xiao72\.env
```

填这一行：

```ini
X72_API_KEY=sk-你的key
```

保存。**这个文件不要发给任何人**（已被 git 忽略）。

## 二、日常使用

### 双击桌面「小72 灯控助手」

等一两秒，出现：

```
==============================================================
  小72 · 灯控助手
==============================================================
  串口：COM8
  模型：deepseek / deepseek-chat
==============================================================
  直接输入中文说话；:state 看状态  :raw 看原始输出  :quit 退出
==============================================================

>
```

**看到 `>` 就开始打字。** 输入中文，回车。

## 三、能说什么

### 调亮度

| 你说 | 效果 |
|---|---|
| 灯好亮啊 / 太刺眼了 | 调暗到 40% |
| 灯太暗了 / 看不清 | 调亮到 80% |
| 调到 60% / 一半亮度 | 按字面值 |
| 全亮 / 最亮 | 100% |
| 暗一点 | 约 40% |

### 呼吸效果

| 你说 | 效果 |
|---|---|
| 呼吸灯 / 呼吸模式 | 80% 亮度，2 秒周期 |
| 慢慢呼吸 | 4 秒周期 |
| 快一点闪 | 0.8 秒周期 |
| 调暗然后慢慢呼吸 | 合并处理 |

### 关灯

| 你说 | 效果 |
|---|---|
| 关灯 / 关掉 / 别亮了 | 熄灭 |
| 我要睡觉了 | 熄灭 |

### 会被拒绝的（AI 不该瞎编）

| 你说 | 回应 |
|---|---|
| 把机械臂转过来 | "机械臂还没接入" |
| 开空调 | "只能控制灯" |
| 你叫什么名字 | "我是小72…" |

**这些被拒绝是好事**——说明 AI 没有幻觉，不知道的事会老实说。

## 四、命令速查

| 输入 | 作用 |
|---|---|
| 任意中文 | 正常对话控制 |
| `:state` | 看当前亮度和周期 |
| `:raw` | 看 AI 原始输出（调 prompt 调试用） |
| `:quit` | 退出 |

**退出后窗口会停住**，按任意键关闭。

## 五、常见问题

### 双击没反应 / 闪一下就没了

去 `host` 目录**双击 `start_xiao72.bat`**，能看到完整报错。

### 提示"没检测到串口设备"

1. USB 线插好了吗（有些线只能充电）
2. 设备管理器里有 CH340 吗
3. 端口被别的程序占了吗（**关掉串口助手**）

### 提示"还没填 API key"

按上面第一步填 `.env`。

### 灯不动，但屏幕上 AI 回了话

说明 AI 和协议正常，问题在硬件链路：

- 看 OLED 第 4 行 `RX` 有没有涨
  - **涨了但灯不动** → PWM 问题
  - **不涨** → 串口没通（检查 TX/RX 是否交叉、GND 是否共地）

### 中文显示成乱码

`start_xiao72.bat` 里已有 `chcp 65001`，如果还乱码，检查系统区域设置。

## 六、OLED 屏幕上显示什么

```
X72 RUNNING       ← 运行状态（收到过命令才变 RUNNING）
BRI:040%          ← 当前实际亮度
PER:2000ms        ← 呼吸周期（0 = 常亮）
RX:0051  E:00     ← 收字节数 / 失败帧数
```

**`E` 不是 0 说明有帧被拒收**，通常是串口助手发的时候格式不对（比如 HEX 模式）。

## 八、手动启动（不想用快捷方式）

```powershell
cd C:\Users\ROG\Documents\deepseek-harness\default-workspace\xiao72\host
python main.py --port COM8
```

`--port` 可以不写，程序会自动找。

其他参数：

| 参数 | 作用 |
|---|---|
| `--mock` | 用离线规则版，不花 API 费用（测试用） |
| `--dry-run` | 只打印帧，不发串口 |
| `--ack` | 等板子回 OK（本版固件没实现应答） |
