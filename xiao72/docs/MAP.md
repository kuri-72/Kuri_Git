# 小72 · 项目地图（一页纸）

> 目的：让你**看见自己建了什么**，并分清"必须懂"和"只需知道存在"。
> 判据：✅ = 出问题时你需要能定位；⬜ = 当黑盒用，坏了再查。

## 一、三层结构（从上到下）

```
┌───────────────────────────────────────────────────────────┐
│  ① 你说的话                                                │
└──────────────────────┬────────────────────────────────────┘
                       ▼
┌───────────────────────────────────────────────────────────┐
│  voice/audio/          听                                │
│    devices.py    ✅ 选哪个麦克风、什么采样率               │
│    recorder.py   ✅ 录成 16k 单声道、调音量                │
│    vad.py        ⬜ 判断"你说完了"                          │
└──────────────────────┬────────────────────────────────────┘
                       ▼
┌───────────────────────────────────────────────────────────┐
│  voice/asr/            转文字                              │
│    faster_whisper_provider.py  ⬜ 音频→文字（含提示词）      │
│    base.py                     ⬜ 接口定义，方便换后端       │
└──────────────────────┬────────────────────────────────────┘
                       ▼
┌───────────────────────────────────────────────────────────┐
│  host/                 想                                 │
│    intent.py     ✅ 文字→意图（问 AI）                      │
│    state.py      ✅ 意图→状态→协议帧                        │
│    serial_link.py ✅ 发串口（COM8）                         │
└──────────────────────┬────────────────────────────────────┘
                       ▼
┌───────────────────────────────────────────────────────────┐
│  firmware/             做（在 STM32 上跑）                  │
│    x72_proto.c   ✅ 把 `[L00502000|A---|]` 解析成数字       │
│    x72_port.c    ✅ 数字→PWM 占空比                         │
│    USART1.c      ✅ 收串口字节（中断 + 环形缓冲）           │
│    x72_app.c     ✅ 在 OLED 上显示                          │
└───────────────────────────────────────────────────────────┘
```

**一句话记法**：**听 → 转 → 想 → 做**

## 二、你只需要记住 4 个数

| 数字 | 含义 | 在哪用到 |
|---|---|---|
| **16000** | 音频采样率（16kHz） | 所有音频处理 |
| **512** | VAD 每帧采样点数（=32ms） | vad.py |
| **1200** | 说完判定：静音 1200ms | run_voice.bat `--silence-end` |
| **100** | 亮度是 0~100 的百分比 | 协议帧里的数字 |

---

## 三、协议帧（唯一需要背下来的格式）

```
[L00502000|A---|]
 │  └┬─┘└─┬┘ └┬┘
 │   亮度  周期  机械臂占位（现在固定 ---）
 │   0050  2000
 └ 灯段标志
```

- **亮度** 4 位：`0050` = 50%（不是 5%）
- **周期** 4 位：`2000` = 2000ms 呼吸一次，`0000` = 常亮
- **机械臂** 预留，以后填 `A090180072`

**为什么这样设计**：固定宽度 + 分隔符，丢了字节能被检测出来，不会错位乱执行。

## 四、三个入口（你日常只用一个）

| 命令 | 用途 | 什么时候用 |
|---|---|---|
| `.\run_voice.bat` | **语音控灯**（主入口） | 日常 |
| `.\run_asr.bat --file xxx.wav` | 只测语音识别 | 识别不准时 |
| `python voice\check_audio.py` | 只测麦克风 | 听不到时 |

**注意**：全部要用 `E:\xiao72-venv` 里的 Python，`.bat` 已经处理好了。

## 五、出问题先看哪一层（按症状查）

| 症状 | 先查 | 具体动作 |
|---|---|---|
| 完全没反应 | ① 听 | `python voice\check_audio.py --stability` |
| 屏幕显示"没听到语音" | ① 听 | 靠近麦克风，或加 `--input Realtek` |
| 识别出来的字不对 | ② 转 | `.\run_asr.bat --record 5` 单独测 |
| 字对了但灯不动 | ③ 想 | 看是不是 `unknown`（AI 拒绝了） |
| 帧打印了但灯真不动 | ④ 做 | 串口松了 / 板子没上电 / 波特率 |

**这个顺序能把 90% 的问题一次定位到层。** 不要一上来就改代码。

## 六、你现在拥有的"保险"（不是功能，是护栏）

| 东西 | 作用 | 少了会怎样 |
|---|---|---|
| `docs/protocol.md` | 协议唯一标准 | 改一处忘另一处 → 两端打架 |
| `host/verify.py` | 两端一致性测试 | 协议静默不匹配，调试 3 天 |
| `firmware/sim_main.c` | PC 上跑单片机解析器 | 每次改解析都要烧板子 |
| `.gitattributes` | 保证 .bat 是 CRLF | 换电脑 bat 全废 |
| 三设备 Git 同步 | 代码不丢 | 换电脑从零开始 |

**这些是你第 30 天就有、很多人第 90 天才补的东西。**

## 七、不必现在懂、也不用担心的

| 东西 | 为什么可以不管 |
|---|---|
| Silero VAD 内部神经网络 | 它给 0~1 概率，你只用阈值 |
| Whisper 模型结构 | 它吃音频吐文字，参数 3 个 |
| ctranslate2 / onnxruntime | 库的运行时，装了就行 |
| 环形缓冲区（FIFO） | 一种"先进先出"的队列，代码已经写好 |
| 采样率重采样 | 16k 是目标，其他率自动转 |

**遇到这些报错，直接把错误贴给我，不用自己啃。**

## 八、下一步的三条路（不急）

```
现在 → 能说话控灯
  ├─ P4 TTS     让灯"回话"（体验提升明显，技术最简单）
  ├─ 唤醒层     不用一直监听（先做"按键唤醒"最简单）
  └─ 设备抽象   为接机械臂做准备（最重要，但最抽象）
```

**建议顺序：P4 → 设备抽象 → 唤醒**。
理由：P4 最快见效，能给你正反馈；设备抽象是地基但抽象，放在你状态好时做。
